# Serpent Chromium 扩展

该扩展支持在 Chrome、Edge 等 Chromium 浏览器中右键网页图片或视频，并将媒体保存到正在运行的 Serpent 桌面应用。

媒体由**浏览器侧下载**（携带 Cookie 与页面 Referer），再上传到本机 Serpent，可绕过多数防盗链限制。只要 Serpent 在运行且已打开资源库，扩展即可连接（本机 127.0.0.1）。

## 构建

在 Serpent 项目根目录运行：

```bash
npm run extension:build
```

可安装产物生成在 `dist/extension/`。该目录包含编译后的 JavaScript、Manifest 和 PNG 图标；不要直接加载源码目录 `extension/`。

## 手动安装

1. 先完成上述构建。
2. Chrome 打开 `chrome://extensions`；Edge 打开 `edge://extensions`。
3. 开启“开发者模式”。
4. 点击“加载已解压的扩展程序”，选择 `dist/extension/`。

## 使用

1. 启动 Serpent 并打开一个资源库。
2. 扩展工具栏图标在已连接时会变为彩色；未连接时保持灰色。
3. 在网页图片或视频上右键，选择「保存到 Serpent」，再选择「根目录」或目标文件夹。
4. **拖拽保存**：拖拽网页图片或视频时自动展开树状保存菜单——悬停有子目录的文件夹右侧 `›` 进入下一级，点击或悬停左侧 `‹` 返回上一级，在目标文件夹上松开即可保存；在面板外部松开或按 `Esc` 退出且不保存。菜单顶部优先展示最近使用的文件夹。

拖拽解析会优先使用浏览器提供的媒体元素与拖拽数据，再回退到坐标命中，因此链接、遮罩、懒加载容器和 CSS 背景图也能保存。要在 Chrome/Edge 中拖拽或右键保存本地 `file://` 图片，请在扩展详情页打开“允许访问文件网址”；本地图片会在页面内转换为 PNG 上传，不暴露本地绝对路径。
5. Pinterest、Behance、Google 图片等站点与常见网页相同，使用浏览器原生右键菜单中的「保存到 Serpent」子菜单，拖拽时同样支持树状保存菜单。

扩展会提供保存反馈，明确提示保存请求已接收、Serpent 未运行、浏览器下载失败，或桌面应用给出的具体拒绝原因。最近使用过的文件夹会排在菜单前列。Serpent 客户端会对扩展保存执行与本地导入相同的内容查重。扩展不会自动启动桌面应用。

桌面应用内打开「设置 → 插件」或「设置 → 常规」可查看扩展相关信息。

扩展选项页（右键扩展图标 → 选项）可配置：系统通知提示、保存后聚焦 Serpent 应用、保存后在资源库中定位该资产，以及是否开启拖拽时的树状保存菜单。
