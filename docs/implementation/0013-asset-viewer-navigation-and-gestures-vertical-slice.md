# 0013 — 资产查看页面导航与手势体验

> 目标版本：v0.1.0
> 状态：P0 正确性缺陷待修 + backlog UX（滚动深处进入查看器偶发严重错位需先修）
> 建立日期：2026-07-14

## 背景

当前资产查看页面已经能够显示媒体、前后切换和退出，但仍是工程可用状态，尚未达到核心浏览工具应有的查看体验。主要问题是默认媒体尺寸、工具栏语义、缩放和平移手感，以及查看页面与资产浏览页面之间的导航关系不够自然。

本切片只记录并收口查看体验，不在本次需求记录阶段修改生产代码。

2026-07-14 新增现场反馈：从资产浏览页双击进入查看时，有概率发生严重位置错位。该项不是视觉打磨，而是核心查看正确性缺陷，按 P0 先建立滚动深处复现用例并修复；其余工具栏、手势与平移仍按本切片原型流程推进。首要排查查看层位于保留 `scrollTop` 的滚动画布内部这一布局边界，根因必须以红测或真实应用复现为准。

## 产品语义

- **资产浏览页面**用于浏览文件夹、搜索结果、合集等资产集合。
- **资产查看页面**是从资产浏览页面进入的临时深入状态，不是弹窗，也不是独立窗口。
- 双击或按 Space 进入资产查看页面；按 Esc 或触发左上角“返回”回到原资产浏览上下文。
- 这里的动作语义是“返回”，不是“关闭”。“关闭”保留给窗口、资源库、弹窗或其他可被关闭的独立表面。
- 显式全屏是资产查看页面内的可选显示动作，不等于进入资产查看页面。
- 用户在查看期间切换文件夹、合集、标签、智能合集、回收站或其他资产范围时，应用先退出查看页面，再显示目标范围的资产浏览页面。

## 范围

### 1. 默认适配媒体

- 打开图片时，默认采用“适合面板”模式：在不裁剪、不变形的前提下，尽可能撑满可用查看区域，并完整呈现整体。
- 视频及其他支持内置查看的资产遵循同一默认适配原则；视频控件占用的空间必须进入可用区域计算。
- 切换上一项/下一项时，每项资产重新计算自己的初始适配，不继承会导致内容跑出视野的上一个资产变换。
- 窗口、左右侧栏或查看区域尺寸变化后，处于默认适配状态的媒体自动重新适配。

### 2. 简化查看页面控件

- 查看页面底部不常驻显示缩小、百分比、放大、适合窗口等缩放 UI。
- 不保留当前占满顶部的工程式 toolbar。
- 实施前先研究 macOS Quick Look / Preview、Windows Photos、Eagle 等成熟查看器的媒体切换、返回、计数和操作呈现方式，并产出低保真交互原型。
- 首选方向是无顶部栏的沉浸画布；若必须提供可见返回入口，则使用左上角轻量“返回”按钮，语义和移动端层级返回一致。
- 上一项/下一项优先使用键盘方向键、画布边缘轻量控件或其他不遮挡内容的成熟模式，最终方案由原型和人工 UX 验收决定。

### 3. 缩放输入

- macOS 触控板 pinch 缩放必须明显提高灵敏度，避免需要反复大幅捏合才能看到变化。
- Ctrl+鼠标滚轮和触控板 pinch 进入同一归一化缩放管线，但允许按设备类型使用不同灵敏度系数。
- 缩放中心是指针或手势焦点所在的媒体位置，缩放后该内容点应尽量留在焦点下方。
- 设置合理的最小/最大比例、速度曲线和数值稳定区，避免跳变、漂移与轻微触摸造成抖动。

### 4. 平移视图

- 放大后支持直接、低延迟地移动视图，且不得与点击、图片切换、浏览区滚动或视频控制冲突。
- 实施前比较至少以下输入：按住鼠标拖动、Space+拖动、中键拖动、触控板双指平移；根据平台习惯选择默认组合。
- 拖动过程中使用明确的抓取光标和边界反馈；释放后不产生意外点击。
- 当媒体小于查看区域或处于默认适配状态时，避免无意义漂移；放大后允许查看全部边缘，不把内容永久拖出可恢复范围。
- 提供可靠的回到默认适配方式，但不要求常驻底部缩放条。

### 5. 导航与状态恢复

- 从资产浏览进入查看时保存来源范围、滚动位置和当前资产。
- Esc 或“返回”后，恢复原浏览范围、原滚动位置和当前资产选择/焦点。
- Esc 返回必须在图片画布、视频原生 controls、倍速选择器等任意查看页焦点位置都可靠生效；原生媒体控件不得吞掉返回键。显式全屏时第一次 Esc 先退出全屏，回到嵌入查看页后再次 Esc 才返回资产浏览。
- 前后切换资产时同步 Inspector、当前选中资产和会话恢复状态。
- 切换文件夹或其他资产范围时退出查看，不把旧查看资产带入新范围。
- 不允许标题、Inspector 和媒体内容在切换过程中短暂显示为不同资产。

## 非范围

- 不在本切片增加图片编辑、标注、裁剪或颜色校正工具。
- 不实现 3D 模型等尚未进入 MVP 的新格式查看器。
- 不重做缩略图生成、视频代理或格式解码管线；这些仍属于 0006。
- 本文不预先锁定最终按钮外观和动画，先通过竞品研究与原型确定。

## 验收条件

1. 宽图、长图、方图及视频首次打开均完整可见、无裁剪、无变形，并尽可能占满查看区域。
2. 查看页面没有常驻底部缩放 UI；顶部不再出现当前工程式 toolbar。
3. Esc 与可见“返回”入口（若保留）产生相同结果：回到来源资产浏览页面并恢复滚动、选择和焦点；图片、视频 controls、倍速选择器分别获得焦点时都必须通过回归测试。
4. 切换文件夹、合集、标签、智能合集或回收站时自动退出查看页面，目标浏览范围正确。
5. 触控板 pinch 和 Ctrl+滚轮缩放方向一致；pinch 灵敏度通过真实 macOS 设备人工 QA，不只依赖合成 wheel 事件。
6. 缩放围绕手势焦点；自动化验证缩放前后的内容坐标误差在约定容差内。
7. 放大后可用鼠标和触控板完成平移并到达媒体四个边缘；拖动不会触发资产切换、点击或文件拖放。
8. 图片切换、窗口 resize 和侧栏变化不会继承错误变换，也不会出现标题/Inspector/媒体错项。
9. Electron E2E 覆盖进入、适配、切换、返回和范围切换；真实 macOS QA 覆盖 pinch 与平移手感，Windows 保留真实设备 QA 结果。
10. 在平铺/瀑布流、96/320 卡片尺寸下分别滚动至列表 25%、50% 和底部后进入查看，查看层与画布 viewport 四边误差不超过 1px，媒体位于内容区内且居中；返回后恢复原滚动位置与资产焦点。

## 实施前置产物

- 一份查看器竞品交互对比，关注返回语义、前后切换、控件显隐、缩放和平移。
- 一个可操作低保真原型或独立 prototype，用真实宽图、长图、视频验证布局和手势。
- 明确的输入映射表与平台差异，不依赖开发人员凭感觉调整单个 wheel 常数。
