## MVP 验收主线

导入或链接图片与视频 → 立即浏览 → 用文件夹/标签/元信息整理 → 关键词/过滤/排序找到目标 → 悬停预览/资产查看页面/显式全屏确认 → 外部应用打开。详见 `docs/product-brief.md`。

## 版本排期决定（2026-07-13）

- `v0.1.0`：完成产品简报既有 MVP，发布阻断范围为 0001–0010 及跨切片桌面主线。
- `v0.1.0` UX 收尾：0012 的字段显示配置已完成；0013 的查看体验与 0014 的选择/上下文操作在核心正确性缺陷先修后实施。0013/0014 的完整 UX 编码前必须完成竞品研究和交互原型，但已复现的查看错位、菜单无法关闭不等待完整原型。
- `v0.2.0`：交付 0011 一等 CLI。该需求已经确认，不再回到探索状态；之所以排在 v0.2.0，
  是因为 CLI 横跨全部领域命令、跨进程写租约、持久变更序号和独立分发，必须建立在
  v0.1.0 已验收的领域语义之上。
- 这不是桌面客户端优先于 CLI；两个客户端仍是同等的一等入口。这里只表达实现依赖和版本风险。
