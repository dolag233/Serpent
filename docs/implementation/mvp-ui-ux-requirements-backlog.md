# Serpent MVP UI/UX 与文件管理需求池

> 状态：生效，需求继续收集中
> 建立：2026-07-16
> 适用版本：除明确标记为 MVP 后的条目外，均进入 v0.1.0 MVP 排期
> 来源：2026-07-16 产品负责人两轮真实使用反馈

## 用途

本文是 0013/0014 之后新增 UI、UX、浏览、文件夹、标签、国际化与主题需求的共享入口。
后续 agent 开始相关工作前必须先阅读本文，并在实施时把条目拆入独立垂直切片规格、开发日志、审查和 QA 文档。

本文不是“已经实现”清单。除非 `docs/qa/human-acceptance-checklist.md` 中存在独立的待验收条目，否则本文中的需求都不得向用户宣称可验收或已完成。

## 已确认产品方向

1. UI/UX 当前以 Eagle 的信息密度、控件分组和美术工作流为主要方向参考，但不复制其品牌和每个像素。
2. 浏览、导航、过滤、文件夹和 Inspector 是 MVP 核心工作流，不推迟到所有底层功能完成以后再处理。
3. 资产只使用真实文件名作为名称；撤销独立 Label/显示别名产品概念，详见 ADR 0022。
4. 标签主要用于过滤与资产元数据，不在左侧导航枚举全部标签，也不建立独立标签管理页面。
5. 中文和英文、亮色和暗色主题进入 MVP；自定义主题推迟，但 MVP 的 token 架构不得阻塞后续扩展。
6. 普通文件夹与链接文件夹在导航中使用同一棵目录结构呈现；链接性质和离线状态通过图标、颜色与 tooltip 表达。
7. 右键菜单随单项、多选、文件夹、回收站和链接状态变化，但共享同一套视觉组件、命令定义、快捷键和危险操作语义。

## 右键菜单语义基线

单资产菜单的默认分组方向：

1. 打开：默认应用打开、其他应用打开、在 Finder/Explorer 显示。
2. 剪贴板与组织：复制、粘贴、重命名、复制文件路径、移动到文件夹。
3. 元数据：标签、合集、AI 分析等当前上下文允许的操作。
4. 删除：移至回收站、永久删除；破坏性操作独立分组并确认。

多选菜单只显示对选择集合有定义的动作。混合 managed/linked/missing/trashed 时必须按固定快照计算目标，并明确说明跳过项。文件夹菜单复用相同的组、快捷键和危险状态，但调用独立的文件夹领域命令。

## 文件夹浏览模型约束

Renderer 需要消费显式的混合浏览项，而不是把目录伪造成资产：

```text
BrowseEntry = FolderBrowseEntry | AssetBrowseEntry

FolderBrowseEntry
  folder_id
  location_kind = managed | linked
  name
  status
  direct_asset_count
  recursive_asset_count
  child_folder_count
  cover_artifact_ids[]
```

封面选择、计数和后代范围由 Worker 批量计算。Renderer 不接收绝对路径，不逐卡查询数据库或文件系统。

## 集中澄清队列

以下问题尚未由产品负责人确认，后续 agent 不得自行猜测；等本轮反馈结束后一次性提问：

1. 左上角“按钮”的完整需求文字。
2. 文件夹显示的数量是直接资产数、递归资产数，还是同时显示两者。
3. 文件夹封面从直接资产还是所有后代资产选图，以及排序规则。
4. 文件夹卡片是否参与与资产相同的框选和多选操作。
5. “复制/粘贴”指 Serpent 内部资产/文件夹复制，还是操作系统文件剪贴板，或两者都要。
6. 文件夹右键菜单反馈末尾“删除、文件夹”是否遗漏“在文件浏览器中打开”等动作。
7. 正常视图中的“删除文件”是否等同永久删除源文件，以及 managed/linked 的确认差异。
8. 不设置标签管理页面后，标签重命名和全局删除从过滤 popover、Inspector 还是其他入口进入。
9. ~~旧 Label 值如何迁移。~~ 已确认：v0.1.0 发布前测试数据直接丢弃，不映射为其他概念；含 Label 条件的智能合集删除。
10. 框选修饰键的精确集合运算：替换、并集、差集、对称差，以及 Shift/Ctrl(Command)+Shift 的定义。
11. 主题默认跟随系统还是沿用暗色；语言默认跟随系统还是首次选择。
12. 后退/前进记录哪些状态：文件夹/合集/搜索/过滤/滚动位置，以及查看页面是否进入历史栈。

## 验收与证据要求

- 每个切片先完成可操作原型或真实应用路径，再进入实现；Eagle 只作为方向参考。
- 0015–0019 的新增功能在当前合流状态完成相关自动化、Computer Use 和截图证据前，不得进入人类待验收队列。
- 图片预览必须验证 `complete && naturalWidth > 0`；文件夹封面和 Inspector 缩略图也适用。
- 主题至少截图检查亮/暗两套的应用壳、画布、右键菜单、Inspector、空/加载/错误状态。
- 本地化至少检查中英文长文本溢出、快捷键标签、错误原因和重启持久化。
- 小卡片/瀑布流必须覆盖多种窗口宽度和 96/160/320 卡片尺寸，证明首尾可达且横向空间合理利用。
