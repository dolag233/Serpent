# 主视图编辑、目录创建与新建库位置选择

工单 `Serpent-aa43fc`，基线 `ebb7f9be`。

- `CARD-RENAME-046` 在主视图用 F2 或现有入口进入编辑后，鼠标可在文件和文件夹名称输入框拖选一段文字。退出编辑后，卡片可继续拖动。
- `LIBRARY-CREATE-PICKER-047` 新建本地库时，系统位置选择器可以停留任意时间。确认位置后，才进入现有资源库加载流程；取消位置选择可继续使用原来的界面并重试。
- `CANVAS-CREATE-FOLDER-048` 在资源库根目录或其他可写文件夹浏览视图，右键空白处可新建文件夹。通过现有编辑与创建流程提交到当前目录。聚合、搜索结果、回收站等没有唯一可写父目录的视图不显示此项。
