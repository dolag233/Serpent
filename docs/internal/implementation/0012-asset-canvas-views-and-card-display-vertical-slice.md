# 0012 — 资产画布视图与卡片信息配置

> 目标版本：v0.1.0
> 状态：ready（需求已确认，排在 0006 媒体正确性收口之后、最终 MVP QA 之前）
> 预计：2–3 工程日，不含 Windows 人工 QA

## 目标

把资产浏览画布从“能显示”收口为稳定、可配置且跨输入设备一致的核心 UX。该切片不改变资产、标签或合集领域语义，只管理客户端显示偏好。

## 范围

- 平铺与瀑布流都支持连续纵向浏览，不提供页码或上一页/下一页。
- 卡片尺寸可以用设置控件、Ctrl+鼠标滚轮和 macOS/Windows 触控板 pinch 调整；普通滚轮只滚动。
- 缩放前记录视口内的锚点资产，重排后保持该资产仍在当前视野，避免用户丢失上下文。
- 用户可以独立设置卡片是否显示名称、文件大小、修改日期；后续字段沿相同 schema 扩展。
- 视图模式、卡片尺寸和字段开关跨重启保存，并对所有文件夹、标签、合集、智能合集和回收站一致生效。
- 隐藏可见名称时，卡片仍保留可访问名称、tooltip 与屏幕阅读器语义。

## 非范围

- 不做每个文件夹单独配置。
- 不做复杂主题、卡片模板编辑器或任意 CSS。
- 不改变数据库资产元数据；显示偏好属于客户端状态。
- 不以该切片阻塞 0006 的媒体解码/预览正确性修复。

## UX 决定

核心可用性 UX（媒体正确显示、连续浏览、无裁剪、统一缩放、视觉锚点、会话恢复）属于 MVP，必须随核心功能并行收口。纯呈现配置（显示哪些字段）在媒体正确性之后实施，但必须在 v0.1.0 最终 QA 之前完成，不能全部推迟到“核心功能结束后再优化”。

## 验收条件

1. 名称、大小、日期可独立开关，默认保持当前信息密度；重启后恢复。
2. 两种视图和所有浏览范围使用同一设置，无每卡 IPC 或 N+1 查询。
3. 96/160/320 三档及 Ctrl+Wheel/pinch 的实际卡片宽度、上下限与方向有自动化验证。
4. 普通滚轮不缩放；缩放后原视口锚点资产仍可见。
5. 瀑布流在 `scrollTop=0` 时第一项完整，在滚动到底时最后一项完整。
6. 至少 10 万资产数据规模下，字段开关不触发后端重查，不显著降低滚动帧率。
7. Electron E2E 覆盖设置持久化、所有浏览范围一致性和可访问名称。

## 实施边界

- Renderer 保存版本化偏好对象；迁移未知/损坏值时回退默认设置。
- 卡片只消费现有 `AssetSummary` 字段；若新增展示字段需要后端数据，必须批量进入列表查询，禁止逐卡请求。
- 平铺与瀑布流使用同一滚动根和缩放输入归一化工具。
