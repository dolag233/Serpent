## 建议的第一批菜单

1. **新建文件夹**。保留已验收的可写实际目录入口。当前菜单已经可以同时呈现内建操作与插件命令。[菜单渲染](../../../src/renderer/AssetContextMenu.tsx#L792) · [目录范围规则](../../../src/renderer/folder-browse-canvas.ts#L101)
2. **粘贴**。优先补齐最常见的右键文件操作，显示当前平台的 `Ctrl+V` / `⌘V`。复用编辑菜单、快捷键和目录右键已有的剪贴板分派，保留图片、文件、剪切移动各自的处理。建议首批仅在可确定目标的目录显示，执行前检查目标仍属于当前资源库和浏览范围。[剪贴板分派](../../../src/renderer/App.tsx#L9031) · [已有目录命令和提示](../../../src/renderer/commands/sidebar-commands.ts#L228)
3. **导入文件… / 导入文件夹…**。与「粘贴」同属添加内容，两项沿用资源库菜单文案和原生选择器。保留已有冲突处理与导入后定位。目录入口应使用当前目录作为目标。[现有资源库菜单](../../../src/renderer/main-menu-items.ts#L190) · [导入流程](../../../src/renderer/App.tsx#L10181)

## 各视图的落点

| 视图 | 建议 |
| --- | --- |
| 资源库根目录、可写托管目录 | 显示上述三类动作。目录递归浏览下依然以当前目录为落点。 |
| 可用链接目录 | 沿用实际目录的资格与现有链接导入分支。首批验收覆盖链接根、链接子目录和断开状态，离线目录不展示新增写入操作。 |
| 所有资产 | 可提供明确标成「导入到资源库根目录…」的入口。现有粘贴快捷键在该视图落到根目录，若提供菜单入口则明示同一落点。 |
| 标签、合集、智能合集、搜索结果、回收站 | 首批隐藏目录写入操作。「导入文件…」目前不会把资产加入当前合集，将来若开放应由专门文案或行为说明落点。 |

落点范围依据 [浏览粘贴目标](../../../src/renderer/browse-paste-target.ts#L11)、[目录导航记录导入目标](../../../src/renderer/App.tsx#L6792)、[链接目录导入分流](../../../src/worker/library-service.ts#L45036) 与 [合集视图导入文案](../../../src/renderer/browse-empty-state.ts#L108)。
