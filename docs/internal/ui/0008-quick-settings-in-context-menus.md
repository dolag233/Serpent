# UI direction 0008: 现场快捷设置

> Status: active product/UX constraint  
> Date: 2026-10-30  
> 关联：查看器右键菜单、`docs/internal/ui/0003-keyboard-shortcut-ux-principles.md`、`docs/internal/ui/0004-calm-error-and-copy-ux-principles.md`

设置页仍然是完整清单。和当前画面有关的选项，还要能在用户正在操作的地方改，通常是右键菜单里的二级菜单。用户不需要先记住设置在哪一页。

## 1. 什么要放进现场菜单

同时满足下面几条的，放进当前界面的右键菜单（或同等的现场菜单）：

1. 设置页里已经有这一项。
2. 它作用于用户眼前的画面，例如正在看的视频、当前查看器的工具栏。
3. 点一下就能生效，不必再打开对话框、再选一层目标。

不满足的留在设置页。不要把整页设置搬进右键菜单。

## 2. 菜单怎么写

- 用二级菜单分组，主菜单只留一个短名称，例如「播放」「其他」。
- 文案和设置页用同一句。不要为菜单再起一个名字。
- 动作项写结果，并带上当前数值。例如「快进 2 秒」「快退 5%」。数值变了，菜单上的字一起变。
- 有快捷键的项标出当前生效的键。键被用户改过，菜单跟着改。没有键的项不留空位假装有。
- 两种模式共用同一对快捷键时，快捷键只标在当前模式上。另一种模式的项仍然可以点，用来做一次该模式的跳转。
- 开关项用勾选表示当前是开还是关。切换类项写即将变成的结果，例如「改为按进度」。
- 点选后菜单关闭，设置立刻生效。

## 3. 查看器

查看图片、视频或其他可预览文件时，右键菜单提供：

- **播放**（视频、GIF、音频）：按当前秒数快进和快退、按当前百分比快进和快退、改为另一种跳转方式。当前跳转方式标出快捷键。视频和 GIF 另外有加速、减速，并标出快捷键。音频没有倍速，这两项不出现。
- **其他**：工具栏在靠近时出现、左右箭头在靠近时出现。这两项与设置里的浏览页是同一组开关。名称前写当前状态「开启」或「关闭」。
