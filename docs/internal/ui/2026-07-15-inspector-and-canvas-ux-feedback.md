# 2026-07-15 用户 UI 反馈 — 画布、导航与检查器面板

> 类型：现场 UX 反馈
> 反馈人：产品负责人
> 日期：2026-07-15
> 优先级：框选文本选择 + 面板溢出 = P0 功能缺陷；导航省略号 = P1；检查器面板重设计 = UX backlog(不阻塞功能)
> 详见 `CLAUDE.md`→Memory Index→`ui-feedback-marquee-inspector-nav`

## 1. 框选时触发浏览器文字选择(功能缺陷)

**现象**：鼠标拖拽框选(marquee)时，画布上的文字出现浏览器默认深蓝色选中背景。

**应修**：完全屏蔽框选期间的文字选择行为。在 `.workspace-canvas` 和 marquee overlay 上设置 `user-select: none`；或在 marquee mousedown/mousemove 中 `preventDefault` 阻断选择事件。

> 这是功能缺陷(非视觉打磨)——框选是 0014 P1 的核心功能，文字选择干扰是可用性 bug。

## 2. 框选溢出到侧边面板(功能缺陷)

**现象**：从资产画布向左侧资源导航或右侧检查器方向拖拽框选时，框选 UI 覆盖到相应面板上方。

**应修**：框选范围必须限制在 `.workspace-canvas` 边界内。marquee 的 `getBoundingClientRect` 应与 canvas 的 rect 取交集；超出 canvas 的部分不渲染 box，也不参与卡片碰撞检测。

> 这也是功能缺陷——框选应只发生在资产浏览区域。

## 3. 侧栏长目录名无省略号

**现象**：资源导航(左侧栏)中，目录名过长接近换行时没有省略号，UI 不整洁。

**应修**：为侧栏目录名元素设置 `overflow: hidden; text-overflow: ellipsis; white-space: nowrap`。

## 4. 检查器面板(资产信息)重设计

以下为产品负责人明确反馈——当前面板有不少"工程可用"痕迹，需按以下方向重设计：

### 信息层级调整

- **删除"当前选择"四个字**：不需要这段标题。
- **资产名称截断修正**：当前只显示 ~4 字符就加省略号，宽度/截断逻辑有 bug。名称应充分利用面板宽度后再省略。

### 属性字段清理

- "修改" → 重命名为 **"修改日期"**。
- "标签(Label)" → **删除"标签"功能**(整个标签修改在这里没用)。同时去掉所有字段名中的英文括号后缀：`(Label)`、`(URL)` 等全部移除→裸中文字段名("源链接"、"色卡")。
- **色卡不允许手动编辑**：改为只读展示(自动提取的色板)。
- "喜欢" → 去掉文字，改用**心形图标**(♡/♥)。无文字标签。
- **评分和喜欢的选中态**：未选中时空心(♡ 空轮廓)，选中后实心(♥ 填充)。评分星星同理(空心星→实心星)。

### 信息密度

- **移除"状态"**字段(不显示 availability)。
- 大小、分辨率、修改日期不再每项单独一行。**合并为一行**：
  `236.2kb | 370 x 589 | 01/23/2026`
- 喜欢(心形图标)也放到这一行(如 `236.2kb | 370 x 589 | 01/23/2026 | ♥`)。
