# UI direction 0003: Keyboard shortcut UX principles

> Status: active product/UX constraint  
> Date: 2026-07-25  
> 关联：REQ-COMMAND-001/002/004、`src/shared/platform-shortcut-table.ts`、beads `Serpent-x78x`

Serpent 的默认快捷键不是「能绑就绑」，而是**可发现、可记忆、跨平台一致、且按一次键就能完成主路径**的少数高价值动作。命令注册表里的 `ShortcutSpec` 与键盘分发必须一致；菜单上写了的键必须真能按出来。

## 1. 什么时候应该有默认快捷键

同时满足下列条件的动作，才进入**默认快捷键**候选池：

1. **一键完成主路径**：按一次（可含标准修饰键）即可触发核心效果；仍可有确认对话框，但**不能**必须先打开选择器、树、TagPicker、文件对话框等才能完成（例如「移动到文件夹」「添加标签」「导入文件」）。
2. **使用频率足够高**：日常浏览、整理、查看媒体时会反复用到；运维/修数据/一次性管理类（复制路径、清空回收站、克隆文件夹、AI 分析等）默认不配键。
3. **有平台或品类习惯可对齐**：Windows 资源管理器、macOS Finder、主流 DAM/查看器（Eagle 等）或 Serpent 已建立的用户习惯。
4. **能在明确上下文中安全接管**：可写清「仅在浏览画布 / 仅在查看器 / 仅侧栏文件夹焦点」等守卫；输入框、对话框、contentEditable、查看器内编辑区聚焦时不抢键。

不满足任一条 → **只保留右键菜单 / 工具栏 / 未来的命令盘**，不写进默认快捷键表。

## 2. 什么时候不应该有默认快捷键

- 必须**二次选择目标**才能完成的组织类操作（移动到文件夹、批量标签、合集成员变更等）。
- **低频或高破坏**且缺少行业统一键位的操作（从硬盘删除库、清空回收站、删除智能合集等）——除非产品负责人明确点名（如 `Shift+Delete` 硬盘删除）。
- **菜单展示与行为不一致**的「幽灵快捷键」：禁止只在 `ShortcutSpec` 里写 label 却不接键盘分发。
- **与已有键位冲突**且无法通过上下文守卫化解的 chord。
- 可通过**鼠标更高效**且非肌肉记忆核心的动作（例如工作区历史后退——保留工具栏/侧键即可）。

## 3. 跨平台规则（Serpent 约定）

| 主题 | Windows | macOS | 说明 |
|------|---------|-------|------|
| 主修饰键 | `Ctrl` | `⌘` (`metaKey`) | `matchesShortcut` 精确匹配，不做跨平台回退 |
| 移入应用回收站 | `Delete` | `⌘⌫` (`Backspace`) | 平台原生差异，写入 `platform-shortcut-table` |
| 硬盘删除（跳过应用回收站） | `Shift+Delete` | `⌥⌘Delete` | 对齐 Explorer / Finder「立即删除」分级 |
| 回收站视图内永久删除 | `Delete` | 实现时对齐平台回收站习惯 | 与普通浏览的 Delete 语义分上下文 |
| 重命名 | `F2` | `F2` | 跨平台一致 |
| 文件复制到系统剪贴板 | `Ctrl+C` | `⌘C` | 资产选中时优先于「复制文本」；mac 用自定义 Edit→Copy |
| 粘贴 OS 文件 | `Ctrl+V` | `⌘V` | 与图片 paste、文本粘贴分焦点守卫 |
| 在资源管理器中显示 | `Ctrl+Shift+S` | `⌘⇧S` | 产品指定（REQ-COMMAND-004） |
| 在所在文件夹中显示 | `Ctrl+B` | `⌘B` | 从「所有资产」等范围跳到该资产所在库内文件夹，居中并选中 |
| 缩放（画布/查看器） | `Ctrl+=/-/0` | `⌘+=/-/0` | Electron 菜单不得注册页面 zoom 抢走 |
| 应用窗口全屏 | `F11` | `⌃⌘F` | 对齐浏览器 / VS Code / Electron `togglefullscreen`。macOS 不用 F11（系统「显示桌面」）。这是窗口全屏，不是查看器元素全屏。 |

实现清单以 [`platform-shortcut-table.ts`](../../../src/shared/platform-shortcut-table.ts) 为 QA 对照表；新增键必须同步注册表 + 命令 `shortcut` + 分发 hook + 单测。

## 4. 上下文与冲突

1. **浏览画布**：资产/文件夹选择、删除、复制、粘贴、搜索聚焦、刷新等。
2. **查看器（图/视频/音频/文本）**：导航、缩放、播放/逐帧/倍速、**音量**（全局偏好）等；捕获阶段处理时需避免壳层 `←/→` 切资产误触。
3. **侧栏树焦点**：文件夹新建/重命名/删除等与画布选中互斥规则（见 `folder-shortcut-dispatch`）。
4. **标签管理工作区**：独立焦点模型，不抢浏览区键位。

冲突处理顺序：**输入控件 > 模态对话框 > 查看器内媒体控件 > 当前工作区表面 > 全局**。新键上线前对照本表与 `platform-shortcut-table` 做冲突矩阵。

## 4.1 自定义快捷键（2026-10-17 R1、R2a、R2b 已实现，待人类验收）

用户可以覆盖内置动作的按键，但覆盖只是一层解析结果，不是第二套快捷键系统。R2a 接入应用菜单编辑与缩放动作，R2b 接入查看器媒体动作；完整方案见 [自定义快捷键完整方案](../implementation/custom-keyboard-shortcuts-plan.md)，落地记录见 [开发日志](../development/2026-10-17-custom-shortcuts-development-log.md)。插件快捷键与鼠标/滚轮手势仍属于后续范围。

必须保持的约束：

- 默认键、用户覆盖、菜单文案、键盘匹配、原生/隐藏加速键从同一份共享目录和解析器产生；任一入口仍读旧常量都算未完成。
- 平台分开保存；Windows 与 macOS 各自一套覆盖，不跨平台套用。
- 自定义不放开输入法、输入框、模态框和查看器的作用域优先级；输入框聚焦时应用快捷键继续让路。
- 裸字母键只允许在查看器等有明确焦点守卫的作用域；全局/浏览作用域必须带修饰键或使用 F 键。
- 冲突以错误提示阻止保存，不提供替换其他动作的入口；用户改录未占用键或取消当前录制。禁止静默双绑；系统保留键集中校验。
- 所有离散快捷键忽略系统自动重复；Windows 隐藏菜单和 `before-input-event` 对同一动作去重。

## 5. 查看器媒体键（2026-07-25 产品定稿）

视频（查看页、非输入框）：

| 键 | 动作 |
|----|------|
| `D` | 上一帧 |
| `F` | 视频下一帧 |
| 小键盘 `.` | 查看器居中适配（图片、视频、序列） |
| `X` | 播放速度降一档（`VIDEO_PLAYBACK_RATES` 上一档） |
| `C` | 播放速度升一档 |
| `Ctrl+←` / `Ctrl+→` | 按设置跳转。默认每次 2 秒；可改为总时长的百分比，默认 5%。见 [0008](0008-quick-settings-in-context-menus.md) |
| `Space` | 播放/暂停 |
| `↑` / `↓` | 全局音量增/减（P1，`Serpent-8w6x`） |

逐帧与倍速**不需要 Ctrl**；勿改为 `,`/`.` 等除非产品重新裁决。

**IME（强制）**：中文等输入法开启时，裸字母键常到不了 Renderer。凡默认字母快捷键（视频 D/F/X/C 等）在 Windows 上必须同时具备：(1) 隐藏 Menu accelerator；(2) 非打字上下文临时 `ImmAssociateContext`/`ImmSetOpenStatus` 关闭转换态；(3) Main `before-input-event` 兜底。禁止做成「仅英文输入法可用」。输入框/对话框聚焦时立刻恢复 IME 并卸掉加速键，不抢打字。

音频查看器共用全局音量与 `↑/↓`（`Serpent-8w6x`）。

### 5.1 查看器指针平移（2026-09-18 产品定稿，`Serpent-16cd1e`）

图片、GIF、视频查看器平移画面：

| 指针 | 动作 |
|------|------|
| 按住鼠标左键拖动 | 平移视图（既有） |
| 按住鼠标中键拖动 | 平移视图（与左键相同） |
| 鼠标右键 | 上下文菜单，不平移 |

中键拖移是从 **Photoshop** 沿用的操作习惯（按住中键当抓手平移），不是新发明的手势。实现落在 `useViewerZoomPan`，图片与视频共用；不要做成查看器里的提示文案。中键按下须取消浏览器默认的自动滚动。3D 查看器的旋转/平移手势不在本条范围。

## 6. 文案与菜单

- 平台相关菜单文案分 locale 键（如 Windows 中文「在文件浏览器中显示」，mac「在 Finder 中显示」），与快捷键标签一并审查长度与准确性。
- 快捷键标签使用平台符号（`⌘` / `Ctrl` / `Delete`），与 `formatShortcut(platform)` 一致。
- 和当前画面有关、点一下就能改的设置，同时出现在右键菜单里。规则见 [0008 现场快捷设置](0008-quick-settings-in-context-menus.md)。

## 8. 变更流程

1. 产品或 UX 在本文件或 backlog 补充原则/新键意图。  
2. 实现：命令注册表 + 分发 + `platform-shortcut-table` + 单测。  
3. 更新 `docs/internal/qa/human-acceptance-checklist.md` 可独立操作步骤（待人类验收）。  
4. Windows 真机键盘验收不得由 macOS 开发态单独代签。
