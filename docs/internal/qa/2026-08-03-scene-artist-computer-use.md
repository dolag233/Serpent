## 已发现问题

1. 连续编号图片会被尝试识别为序列图，但识别前必须校验候选帧的图像尺寸是否完全一致。
2. 批量导入遇到候选序列帧或重复资产时，需要使用批量处理弹窗；普通导入流程保持简单。
3. 清空搜索后侧栏数量曾出现短暂滞后，需继续确认是否为状态刷新时序问题。
4. 本次 Computer Use 无法稳定模拟多选，不应据此判定产品不支持多选；产品已有多选描边、高亮、右侧“共 N 个文件”和右键菜单数量显示。
