## 人工验收步骤

### TABS-001 基本导航与关闭

1. 打开资源库，确认顶部有一个“所有资产”标签。
2. 依次点击文件夹、合集和回收站，确认标签数量不变且当前标签标题随页面变化。
3. 点击加号，确认新增并激活一个“所有资产”标签。
4. 在两个标签内选择不同页面、输入不同搜索、滚动到不同位置，再来回切换。
5. 分别用关闭按钮、右键“关闭标签页”“关闭其他标签页”。

预期：只有加号增加标签；每个标签恢复自己的页面、历史、搜索/筛选、选择和滚动；
关闭最后一个标签时保留并复位为“所有资产”。

### TABS-002 文件夹与合集菜单

1. 打开一个深层文件夹标签，再切到另一个标签。
2. 右键该文件夹标签，依次检查“在文件夹中显示”“复制名称”“复制路径”和
   “在 Finder/文件浏览器中打开”。
3. 右键合集标签，检查“在合集中显示”和“复制名称”。

预期：侧栏自动展开父级并聚焦目标，但不切换活动标签；复制结果正确；文件夹可在
系统文件浏览器打开；合集不显示文件路径动作。

### TABS-003 视觉与可访问性

1. 在亮/暗主题、中英文和窄窗口下创建足够多的标签，观察连续文件夹页签轮廓。
2. 用 ArrowLeft/ArrowRight、Home/End、Delete、Shift+F10 操作。
3. 缩放窗口后检查活动标签与加号。
4. 打开设置 → 层级投影，在 0 与 3 之间切换。

预期：页签顶部与窗口边缘留空隙，上角更圆，不呈现彼此分离的卡片；活动页签
圆滑接入内容区，与范围栏之间没有顶栏底边缝。前进/后退、设置、资源库切换、
搜索框与页签标题垂直居中对齐。文字和图标可读，活动态清楚，加号始终可操作，
键盘操作与鼠标一致。层级投影 1–3 时活动页签投下阴影，强度跟随该设置；
0 时无阴影，且不得因此在页签与范围栏之间再夹一条缝。相邻页签之间没有竖向分割线。

### TABS-004 溢出滑动

1. 打开足够多的标签，使标签条超出可用宽度。
2. 指针停在标签条上，用鼠标滚轮上下拨动。
3. macOS 再用触控板两指左右滑、两指上下滑。

预期：标签条左右移动，画布不跟着滚；加号留在列表外侧。pinch / Ctrl+滚轮
不带动标签条。
