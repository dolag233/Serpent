# 用户文档：插件与自动化功能拆分

> 工单：Serpent-e7rs
> 变更类型：用户文档整理
> 基线：18c5396

## 目标

把面向美术用户的扩展说明从开发者视角改成可直接照着操作的使用指南，并把原来的「插件、脚本与 MCP」拆成「插件使用」和「自动化功能」两篇。

## 本次变更

- 新增中英文《插件使用》：安装来源、GitHub 安装示例、全局/资源库范围、启停、信任、更新、重载、卸载和浏览器扩展下载。
- 新增中英文《自动化功能》：自动化脚本和 MCP 的首次连接步骤、Token 安全提示及影响性操作确认。
- 将旧的 `extensions.md` / `extensions.en.md` 保留为短迁移页，避免历史链接失效。
- 删除用户文档中的插件包格式、压缩包大小、运行时、沙箱、路径和协议限制等实现细节；这些内容仍由扩展作者手册负责。
- 更新中英文用户手册导航、安装页、故障排查页和开发者文档入口。
- 更新根 README 的主页、在线文档、Serpent 发布页和浏览器扩展发布页；安装说明改为指向最新 Release。
