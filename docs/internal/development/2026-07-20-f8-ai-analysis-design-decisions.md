# F8 决议：AI 视觉分析输出与提示词（2026-07-20）

> 来源：用户对 `Serpent-1us6` 的拍板。2026-07-20 用户授权实现。  
> 相关：ADR-0016、产品简报「AI 内容层 / 人工优先」、用户提示词草案。

## 1. 输出字段

| 字段 | MVP | 说明 |
| --- | --- | --- |
| 标签 `tags` | 是 | 可开关写入 AI 层 |
| 描述 `description` | 是 | 可开关写入 AI 层 |
| 美学评分 `rating`（1–5） | 是 | **只写 AI 层**，UI 标注 AI；**绝不写入人工评分** |
| 作者 | **否** | 不做 |
| 自由 `structured_metadata` | **退役** | 新分析不再请求、不再写入；旧库残留可随清空 AI 清掉，不做新 UI |

字段开关与高级参数均可在 **AI 设置** 中配置。

## 2. 可配置项与默认值

**简单开关（设置主区可见）**

- 写入描述（默认开）
- 写入标签（默认开）
- 写入 AI 评分（默认开）
- 强制使用已有标签（默认关）：开启后模型只能从传入的已有标签列表中选，不得发明新标签

**模型高级设置（折叠区）**

| 项 | 默认 | 备注 |
| --- | --- | --- |
| 最大标签数 | **8** | |
| 描述字数上限 | 中文 **100 汉字**；英文 **60 词** | 按目标语言分别计量；中英混排时两者同时约束（实现时取更严） |
| 输出风格 | 正常 | 枚举：正常 / 精简 / 严谨 |
| 描述结构 | 类型 → 风格 → 内容 | 可被「自定义描述 prompt」覆盖 |
| 评分标准提示词 | 内置默认文案 | 用户可整段编辑 |
| 自定义描述 prompt | 空 = 用默认结构 | 非空则覆盖默认描述规则 |
| 语言 | 沿用现有多选 | 已实现 |

## 3. 已有标签如何传入提示词

最多传入 **100** 个标签，排序权重：

1. **当前文件夹**内出现过的标签优先（更高权重）
2. 其次按**全库使用次数**（高频优先）
3. 截断到 100

范围语义：

- 浏览某托管文件夹时：「当前文件夹」= **仅该文件夹本身**，不含子文件夹（与画布是否「包含子文件夹」无关）。
- 全部资产 / 搜索 / 合集 / 智能合集 / 回收站：无文件夹锚点时，仅按全库使用次数取 top 100。

## 4. 配置 UI 形态

仍在现有 **AI 配置** 对话框内，两层：

1. **主区**：连接/协议/Key/模型/语言 + **简单写入开关**（描述、标签、AI 评分、强制已有标签）。
2. **「模型高级设置」**（折叠）：最大标签数、描述上限、输出风格、描述结构/自定义 prompt、评分标准等。

不另开独立窗口。

## 5. 与 AI 内容层 / 人工层

- 一次分析仍 **原子替换该资产 AI 内容**（仅替换本次启用字段对应的 AI 行；未启用字段的旧 AI 值是否保留：建议「仅替换启用字段」，未启用字段不动——实现规格确认）。
- **有人工值的字段，AI 不得覆盖人工层**（与产品简报一致）：
  - 已有人工描述 → **跳过描述**：不请求、不写入 AI 描述（省费用）。
  - 已有人工评分 → **不写人工评分**；若启用了 AI 评分，仍可写入 **AI 层评分**并带 AI 角标（人工星级不变）。
  - 标签：人工标签与 AI 标签本来分轨；「强制已有标签」只约束模型候选，不删人工标签。
- 清空 AI / 编辑转人工：沿用既有 F4/F5 语义（编辑后进人工层并去掉 AI 标记）。

## 6. 提示词骨架（占位符）

```
这是一个视觉分析任务……以严格 JSON 输出：
{ "description": string|null, "tags": string[], "rating": number|null }

规则：
- 输出风格：{output_style}
- 标签：优先/仅使用已有标签；已有标签={existing_tags}；不超过 {max_tags}；
  强制已有标签={force_existing_tags}
- 评分：1–5；标准={rating_rubric}；无把握可 null（若未启用评分则省略）
- 描述：{description_rules 或 custom_description_prompt}；中文≤{max_description_chars}汉字 / 英文≤{max_description_words}词；
  目标语言={target_languages}
```
