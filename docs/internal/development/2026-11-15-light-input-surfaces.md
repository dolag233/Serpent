# 亮色输入框底色微调

工单 Serpent-fv5cq。用户反馈 Inspector 描述、作者与源链接输入框与面板背景过于接近，希望稍微提亮。

复用 ui/islands-surfaces.css 的共享 --island-input-fill，仅在亮色主题下改为主题 inverse 色与面板色混合，比例为 60%/40%。沿用现有输入框选择器，普通、hover、focus 状态统一生效；暗色计算不变，无新增组件或交互。

验证：后台 Edge 加载当前完整 styles.css 和 islands-surfaces.css，对合成中性亮色、淡紫亮色、暗色配色检查描述/作者/链接字段。中性样例由约 RGB(249,249,249) 变为 (252,252,252)，淡紫样例保留轻微色调，暗色前后相同；聚焦和三种字段底色一致。首轮夹具缺少运行时面板变量，计算得到透明底色，补全夹具变量并拒绝透明结果后复验通过。未写入截图或媒体产物。
