# 虚拟画布视口更新：独立双轴审查

审查角色：Luna xhigh 独立 agent。实现者为主 agent；只启动一个最终审查 agent，同时覆盖 Standards 与 Spec。范围为本次两个 Renderer 产品文件及相关单元测试，不包含工作区其他媒体开发。审查只读，不以审查代替用户验收。

## Standards

未发现有证据支持的阻断。复用现有几何序列、窗口二分查询及真实相交判定，没有新建平行布局体系，没有改主题/UI 样式、数据库或跨进程能力。render key 相同时保留挂载区间和每列实际可见成员；精确 scrollTop 在跳过 React 更新前写入 WeakMap，供几何锚点读取。几何回调变更会重新绑定与测量。

## Spec 与回归

未发现有证据支持的正确性回归。瀑布流列和平铺行在同一序列内按单调位置排列，首尾可见状态与区间边界能代表整段成员。保留 overscan 和同步 scroll 响应，没有通过减少挂载范围或延迟更新规避问题。测试包含边界、空隙、尾部、反向、远跳、resize、折叠及旧调用者行为。

审查提出一项需 profile 核实的成本：render key 每次 scroll 都要做几何查询，原分块 offsetAt 最多扫描 128 项。它不是零成本。主 agent 两轮独占真实媒体对照显示脚本样本分别减少约 48%、34%，帧 p95 只有很小变化，图片九成解码没有稳定提速。没有证据将新查询定为回归，也没有把采样下降写成全部性能目标完成。

补充审查真实媒体测试时，Luna 发现一项证据阻断：未断言实际滚动位置和九成解码完成，passed 本身不足以证明目标跳点。主 agent 已补实际比例误差小于 0.01、最终覆盖率至少 0.9 及九成解码时刻非空，并重新构建 HEAD/优化版各跑 1 passed。最终实测比例误差小于 0.0003、覆盖率均 100%。同时排除 profiler 启动阶段对帧探针的干扰，最终帧 p95 18.9→18.7ms，脚本样本 663→437。审查未发现真实源被测试写入或清理的路径；Worker 操作隔离拷贝，E2E 只链接源目录。

主 agent 最终补充了无几何键调用者的精确更新对照，并修正测试类型/夹具；产品实现自审查后未改变。最终定向 36 项、定向 ESLint 通过；真实媒体 HEAD/优化版隐藏 Electron 各 1 passed。全仓类型检查受其他开发文件四项错误阻断，前台 Computer Use 按用户要求未执行，packaged/macOS 未执行。结论仅为此增量无已知代码阻断；待用户体验复验，整体性能工单继续进行。
