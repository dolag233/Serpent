## 三、对第一批条目的复验

- CU-M2「Escape 不能关筛选面板」：**仍存在**（查看页 Escape 可关，筛选面板不可）。
- CU-M2「无激活条件摘要 chip」：部分改善——过滤激活时按钮变蓝+计数变化，但仍无可读的条件摘要与一键清除。
- CU-U2「搜索分词第二行」：**仍存在**，且在真实长文件名库上视觉噪音更明显（D3）。
- CU-U3「多选显示单资产详情」：部分改善——已加「将应用于 N 项资产」批量提示，仍无 N 项汇总视图。
- CU-D2 佐证了第一批建议的目录树折叠需求在真实 25 文件夹库上是硬需求。

## 四、环境备注（给后续 agent）

- 启动命令：`SERPENT_E2E=1 SERPENT_E2E_USER_DATA_PATH=/tmp/serpent-cu2/user-data SERPENT_E2E_OPEN_LIBRARY_PATH="<库路径>" npm start`；electron-forge 启动约 15 秒后会因 Vite 二次构建重启 main 进程，E2E 自动开库 hook 不重放，回退到无库空态——此时点首页「打开资源库」按钮即可恢复（hook 会拦截对话框直接用 env 路径）。
- CU 坐标系：AX bbox 与截图像素一致（1567×843）；`ax_filter` 调用后 index 重排，坐标/index 点击前需先取 `mode="full"` 缓存几何。
- 侧栏滚动后，被裁出可视区的行 bbox 高度为 0/1，index 点击会落到相邻可见行——侧栏操作前先滚回目标可见。
- 合成滚轮对面板类浮层无效（事件落下层网格）；过滤面板无法通过滚轮滚动（即 CU-D6）。
- 拖拽资产到文件夹会变更库内归属（写操作），本批未验证；BUG-DND-001/DND-003 仍按第一批结论移交 Playwright/人工。
