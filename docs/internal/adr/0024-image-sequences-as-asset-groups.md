# ADR-0024：序列图作为持久化资产组

- 状态：已接受
- 日期：2026-07-27

Serpent 把序列图建模为一组仍然各自拥有 `Asset` / `Revision` 身份的图片资产，以及一条持久化的 `AssetSequence` 关系，而不是把多份文件折叠成一个虚构文件。序列以第一帧为主资产；普通浏览、搜索和合集视图只显示主资产卡片，查看页和 Inspector 可以按序列关系读取全部帧。删除主帧或关系不再有效时必须解散序列，使剩余帧重新成为可见资产，不能产生用户无法访问的隐藏文件。

自动识别要求同目录、同扩展名、同数字前缀，并把文件名末尾数字解析为帧号。帧号必须连续且至少三帧；断号会拆成不同候选段。数字宽度参与候选身份，避免 `img_1.png` 与 `img_01.png` 产生重复帧号歧义。单文件导入会检查同目录兄弟文件，但只扩展并导入包含所选文件的有效连续段；文件夹导入会识别所有有效段。自动创建使用 24 FPS，手动创建由用户在 1–240 FPS 内指定。

序列播放在 Renderer 内按 FPS 切换每帧的安全预览 URL，不生成视频文件，也不修改任何源图片。旋转和镜像同样只属于当前查看会话的显示状态，不写入文件、修订或数据库。
