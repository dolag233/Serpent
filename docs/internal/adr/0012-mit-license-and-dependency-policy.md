# ADR-0012：客户端采用 MIT 许可证

- 状态：已接受
- 日期：2026-07-11

## 背景

Serpent 的产品原则是开源、免费，并计划长期提供第三方插件能力。许可证需要允许广泛使用和贡献，同时不能与所选依赖的分发条款冲突。

## 决策

Serpent 客户端采用 MIT 许可证。

引入依赖前检查其许可证与计划分发方式的兼容性。如果某项依赖会要求改变 Serpent 的整体分发许可，则避免采用或通过新的 ADR 明确重新决策。

## 后果

- 第三方可以在 MIT 条款下使用、修改和分发 Serpent。
- 依赖清单需要记录许可证，并在发布流程中执行审计。
- 服务端、插件 SDK 和官方插件是否沿用 MIT，可在它们进入实际范围时分别确认。
