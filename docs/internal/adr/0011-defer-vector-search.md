# ADR-0011：MVP 不使用向量搜索

> 2026-07-16 更新：其中 AI Label 输出与 Label 搜索已被 [ADR 0022](0022-retire-asset-label.md) 取代；AI 继续生成描述、标签和结构化元信息。

- 状态：已接受
- 日期：2026-07-11

## 背景

向量搜索能支持语义相似和视觉相似，但 embedding 与具体模型、版本、维度和预处理方式绑定。更换模型通常需要重算全部向量并重建索引，也会增加存储、部署和调参复杂度。

Serpent 已拥有 Label、描述、标签、来源、文件夹和结构化元信息，可以先建立快速、可解释的全文检索。

## 决策

MVP 不生成或存储 embedding 向量，不提供真正的向量语义搜索或视觉相似搜索。

资产导入后，视觉或多模态模型生成 Label、描述、标签及结构化元信息。用户启用搜索框 AI 按钮时，快速模型把自然语言转换为受约束的查询计划，包括关键词、同义词、排除词和过滤条件；Serpent 再使用普通加权全文检索与结构化过滤执行查询。

## 后果

- 更换 AI 生成模型不会让搜索索引整体失效。
- AI 不可用时，普通搜索仍能工作。
- 模型生成内容必须记录来源模型与版本，以处理新旧描述风格漂移。
- MVP 无法可靠执行按构图、姿态、纹理等特征的视觉相似搜索。
- 只有用户需求证明视觉或语义相似的价值后，才引入可版本化、可后台重建的向量索引。
