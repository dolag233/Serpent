# 0022 — 退役资产 Label/显示别名

> Status: accepted

Serpent 在 v0.1.0 发布前撤销独立的 Label/资产显示别名：资产名称统一为真实文件名，用户要改变名称时执行受领域规则保护的文件重命名；标签继续承担可复用分类与过滤，描述继续承担自然语言说明。保留 Label 会让用户同时理解文件名、显示名和标签三套相近概念，并扩散到搜索权重、AI 输出、智能合集和 CLI，因此在尚未正式发布时承担迁移成本比长期保留低。

后续实现必须移除 Label 的 UI、搜索语法/权重、AI 字段开关和一等客户端协议。

## 预发布迁移决定（2026-07-16）

产品负责人确认 v0.1.0 尚未发布，旧开发库中的 Label 值可以直接丢弃，不迁移为文件名、标签或描述。数据库使用前向迁移重建 `asset_metadata`、AI 内容与 FTS 结构；真实文件名、描述、评分、喜欢、色卡、来源链接和标签关系保持不变。

显式包含 `field = "label"` 条件的旧智能合集不能可靠改写为其他字段。迁移会删除这些预发布智能合集，避免它们在字段消失后静默变成永远为空的结果；不依赖 Label 的智能合集继续保留。
