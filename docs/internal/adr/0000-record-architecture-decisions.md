# ADR-0000：记录重要产品与架构决策

- 状态：已接受
- 日期：2026-07-11

## 背景

Serpent 同时涉及跨平台桌面体验、专业媒体格式、索引与搜索、团队协作、版本管理和插件扩展。关键选择彼此耦合，若只保留最终方案，很难理解其成立条件。

## 决策

使用 ADR 记录会显著影响产品边界、领域模型、技术架构或后续可逆性的决定。

每份 ADR 至少包含背景、决策、理由与后果。尚未确认的方向不写成已接受决策，而保留在产品简报的开放问题中。

## 后果

- 后续访谈中确认的重大决定会新增 ADR。
- 决策变化时保留旧记录，并以新 ADR 替代，而不是覆写历史。
