# ADR-0003：插件采用显式权限声明与用户授权

- 状态：已被 [ADR-0026](0026-plugin-runtime-installation-and-trust.md) 补充并部分替代
- 日期：2026-07-11

## 背景

Serpent 插件可能解析格式、读写资产、执行本地程序、访问网络、扩展 UI、调用 AI 或连接云服务。这些能力可能接触私有素材或改变本地文件。

## 决策

插件清单必须显式声明所需权限。标准插件的敏感能力只有在用户明确授权后才能通过 Host API 使用。

可信插件的完整 Node.js 能力无法被该权限模型可靠约束；其清单用于风险披露和
Serpent API 授权，真实边界、双作用域安装与信任规则以 ADR-0026 为准。

插件扩展点计划覆盖格式解析与预览、导入导出及文件处理、搜索与 AI、UI、存储服务和自动化。

## 后果

- 插件 API 设计必须同时定义能力接口与权限粒度。
- 插件安装和权限升级需要清晰展示风险。
- 沙箱、签名、撤销权限和无代码插件模型仍需后续决策。
