# ADR-0001：采用以文件为中心的资产模型

- 状态：已接受
- 日期：2026-07-11

## 背景

专业创意内容可能由单个文件、图片序列、工程目录或带依赖关系的一组文件构成。若首版直接建模复合资产，需要处理依赖发现、重定位、打包及部分缺失等问题。

## 决策

所有通过导入过滤规则的文件都是独立资产。普通导入会把资产复制进 Serpent 资源库。只有在“导入文件夹”时，用户才能明确选择“以链接方式导入”，使目录内容保留在原位置。

链接文件夹中，Serpent 可以对源文件和源目录执行增删查改。删除和移动操作默认需要用户确认，用户可在设置中关闭确认。

链接文件夹可以配置类似 `.gitignore` 的过滤规则；命中规则的路径不纳入资产模型，Serpent 不对其执行任何文件或文件夹操作。

本段原有的独立虚拟文件夹决定已由 ADR-0013 替代：资源库文件夹映射真实磁盘目录，MVP 不再建立独立的多对多虚拟文件夹实体。

首版不识别或管理文件之间的依赖关系，也不把一组文件包装成一个复合资产。

## 理由

该模型覆盖首发图片与视频场景，同时让格式支持、索引、预览和 AI 元数据成为可以分别扩展的能力。

## 后果

- 文件是资产身份、索引和元数据关联的基础，但稳定 ID 的生成方式仍待设计。
- 复制导入与链接文件夹采用不同的丢失文件、移动文件和删除策略。
- 文件操作需要在失败、部分完成和外部并发修改时保持索引与磁盘状态一致。
- 3D 模型、工程文件和图片序列的依赖管理推迟到未来 ADR。
