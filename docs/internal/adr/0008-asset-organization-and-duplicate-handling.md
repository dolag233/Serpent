# ADR-0008：资产组织与疑似重复处理

- 状态：部分由 ADR-0013 替代
- 日期：2026-07-11

## 背景

Serpent 同时提供多种组织方式，并需要在导入时避免用户无意创建重复资产。过强的自动去重可能错误删除或合并不同内容。

## 决策

- 虚拟文件夹的多对多决定已由 ADR-0013 替代；资源库文件夹改为唯一主要位置并映射真实目录。
- 合集（Collection）是文件夹主结构之外的树状虚拟分类和长期策展视图，可以跨文件夹收集资产且不改变文件位置。一项资产可加入零个或多个合集；合集支持名称、描述、封面和手动排序。
- “喜欢”是布尔状态，并形成自动视图。
- 评分范围为 0–5 星。
- 文件名和文件大小均相同时标记为疑似重复，但不自动执行操作。
- 用户可以选择跳过、合并或创建副本。
- 同一资源库文件夹已存在同名磁盘文件时，提示保留两者、替换或跳过，默认保留两者并为新文件自动追加序号；批量操作可应用到全部。
- 同名且同大小时优先进入疑似重复流程；其中“创建副本”使用相同的自动追加序号规则。
- 合并时保留先加入的文件，并合并双方的标签、合集、喜欢状态和评分等元数据。
- Label、描述、源链接等单值字段冲突时，弹窗逐项选择，并允许“为所有冲突文件执行此操作”。

## 后果

- 内容相同但名称不同的文件不会被提示为重复。
- 名称和大小相同但内容不同的文件可能被提示，但用户仍能选择保留两份。
- 文件夹部分见 ADR-0013；合集、喜欢、评分和重复处理决定继续有效。
