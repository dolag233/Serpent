# 内部开发记录

本目录存放 Serpent 开发过程文档，**不随产品交付**。

| 目录 | 内容 |
| --- | --- |
| `adr/` | 架构决策记录（ADR-0000 起） |
| `implementation/` | 切片实施规格与需求来源 |
| `development/` | 切片开发日志 |
| `qa/` | QA 报告与人类验收清单 |
| `reviews/` | 代码审查报告 |
| `research/` | 技术调研 |
| `ui/` | UI 视觉方向 |
| `skills/`、`superpowers/` | Agent 技能与流程 |

顶层文件：`development-process.md`（切片流程与质量门禁）、`project-status.md`（项目状态）、`domain-model.md`（领域模型）、`agent-*.md`（Agent 协作）、`handoff-*.md`（交接记录）。

交付文档在 [`docs/`](../README.md) 顶层：使用手册、开发者文档、扩展作者手册。
