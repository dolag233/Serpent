# Documentation assets

This directory contains visual assets used by the user and developer documentation.

- `ui/` contains screenshots copied from repository QA evidence. They show real Serpent surfaces and should be refreshed when the UI changes materially.
- `diagrams/source/` contains the editable Mermaid sources for the workflow, extension choice, process architecture, and release pipeline diagrams embedded in the Markdown docs.

Screenshots are evidence-oriented and may contain synthetic fixture names or data; they are not product marketing images.
