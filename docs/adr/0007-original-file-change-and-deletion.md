# ADR-0007：链接文件夹变化、丢失与删除的处理

- 状态：已接受
- 日期：2026-07-11

## 背景

链接文件夹不会复制原文件，因此外部软件可以修改、移动或删除文件。Serpent 也被允许对这些源文件和目录执行文件管理操作。

## 决策

- 外部内容变化后，自动刷新该资产的预览和提取元信息。
- 外部修改是已经发生的磁盘事实，不提供无法兑现的“拒绝修改”动作；检测后自动采用当前内容并显示非阻断通知，批量变化合并为摘要通知。
- 链接文件被外部覆盖后不复制或保留旧文件字节，只记录变化并使旧衍生物失效。
- 资源库中的托管文件被外部软件原地覆盖时，MVP 同样不承诺保留修改前的旧字节。
- 文件在记录路径上消失后，保留资产记录并标记为丢失，不自动猜测任意新路径。
- 用户可以重新定位单个文件，也可以指定新根目录，依据原有相对路径批量找回一组被整体移动的文件。
- 托管文件在 Serpent 以外被移动或重命名时同样采用上述丢失与手动找回流程。重新关联时询问是否沿用原资产信息并支持批量应用；沿用时保留资产级元信息和组织关系，重新生成缩略图、提取元信息和 AI 内容。
- 删除或移动链接文件夹中的文件/目录时弹出确认；用户可以在设置中关闭确认。
- 用户删除链接资产时，弹窗询问是否同步删除磁盘原文件；磁盘删除使用系统回收站。
- 复制进资源库的资产被删除后先进入 Serpent 回收站。
- Serpent 回收站默认保留一个月。
- 清理到期文件时若文件正被占用，跳过并提示，下次清理继续尝试，不使整批清理失败。
- 链接过滤规则命中的文件或目录不被索引、展示或操作。
- 过滤规则通过图形界面配置，支持路径、文件名、扩展名、文件夹和排除条件；内部匹配语法不要求普通用户直接编辑，并提供可修改的推荐默认忽略项。
- 规则变化导致已有资产被忽略时，从界面移除但保留数据库元数据；取消忽略后恢复。
- 普通资产被拖入链接文件夹时，将对应文件复制到真实源目录。
- 链接文件夹可以单向转换为资源库托管文件夹：复制源内容成功后移除链接关系。

## 后果

- Serpent 必须保存足以进行批量重新定位的原始路径和相对路径信息。
- 文件监听需要处理频繁写入、临时文件和应用自身文件操作造成的重复事件。
- UI 必须避免把修订记录表达成可恢复版本；没有旧字节时不能提供恢复动作。
- 空间压力下是否提前清理未到期内容留待未来单独决定；文件占用不触发强制删除。
- 具体内部匹配顺序和默认规则清单在实现阶段通过测试确定，但不得改变图形界面已承诺的条件类型。
