# ADR-0013：资源库文件夹映射真实磁盘目录

- 状态：已接受
- 日期：2026-07-11
- 替代：ADR-0008 中“一项资产可属于多个虚拟文件夹”的部分

## 背景

多对多虚拟文件夹虽然灵活，但会让资源库磁盘目录难以理解。用户希望文件夹继续作为主要组织结构，整体备份资源库后仍能直接理解托管文件位置；跨文件夹的多重归类由合集和标签承担。

## 决策

- 每项托管资产最多属于一个资源库文件夹。
- 资源库文件夹映射 `Assets/` 下的真实磁盘目录。
- 在资源库文件夹间移动资产会移动实际托管文件。
- 在 Serpent 内移动托管资产时保留资产 ID、全部资产级元信息及合集/标签关系，并提供撤销操作。
- 修改 Label 不重命名磁盘文件。
- 复制导入文件夹时完整保留源目录层级；单独导入、拖入或粘贴文件时使用当前资源库文件夹，未选择时进入 `Assets/` 根目录。
- 合集作为树状虚拟分类和长期策展视图，可跨文件夹收集资产且不改变文件位置；一项资产可以加入零个或多个合集。
- 标签承担检索和筛选维度。
- 应用内部数据库、预览、修订和回收站存放在 `.serpent/` 目录。

建议结构：

```text
MyLibrary/
  Assets/
    UI References/
      button.png
    Video/
      intro.mov
  .serpent/
    library.db
    previews/
    revisions/
    trash/
```

## 后果

- 文件夹名称和层级需要满足 Windows 与 macOS 的共同路径约束。
- 同一目录出现同名文件时提示保留两者、替换或跳过，默认保留两者并自动为新文件名追加序号；批量操作可应用到全部。
- 用户直接在 `Assets/` 中修改、移动或删除文件时，Serpent 必须检测并协调数据库状态。
- 标签和合集只存在数据库中，不映射为额外文件副本。
