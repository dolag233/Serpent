## 四、功能与 UX 提案（待产品负责人确认；不实施直到拍板）

1. **工具栏溢出短期折叠**：在 REQ-CANVAS-003 完整迁出前，浏览工具栏按宽度把尾部按钮收进「更多」菜单，杜绝裁切。（对应 P1；交互数不变、实现小）
2. **激活过滤计数徽标**：「筛选与排序」summary 显示当前激活条件数（如「筛选与排序 · 3」），REQ-FILTER-002「条件持续可见」的最小一步；完整 chips 条仍等维度过滤原型。
3. **资产重命名原地编辑**：与文件夹一致（澄清队列 #13 已有，建议确认方向——卡片文件名变输入框，扩展名锁定不选）。
4. **评分控件可读性**：星星从 ~14px 描边增至 16–18px 并提高对比（当前偏暗偏小，05/11 证据）。
5. **查看页胶片条**：查看页底部显示当前范围缩略图 filmstrip，支持点击跳项（美术浏览高频诉求，0013 查看页重设计时一并考虑）。
6. **回收站空态与批量条**：回收站为空时给「清理到期项目」说明；多选回收站资产时把「永久删除 N 项」放到更明显的位置（当前在菜单深处）。
7. **通知历史**：toast 消失后不可追溯，建议在媒体任务对话框内附带最近通知列表（克制实现，不加铃铛常驻图标）。
