## 二、确认 Bug

### B1【状态同步】移出合集后网格陷入「0 项 + 首次导入空态」
在「所有资产」视图对资产执行「移出合集：精选集」后，主网格一度显示「所有资产 0 项」+ 首次导入空态「把第一批素材放进来」，而侧栏仍显示「所有资产 8」。重新点击侧栏「所有资产」后恢复 8 项。数据未丢失，属视图失效（invalidation）不同步。

### B2【状态同步】恢复资产后侧栏/资源库信息计数不刷新
回收站恢复 1 项资产后：网格范围栏正确变为 8 项，但侧栏「所有资产」与右侧资源库信息面板的资产数停留在 7；导航切换后才同步为 8。与 B1 同族，疑似同一 invalidation 缺失根因。

### B3【状态同步】智能合集视图的范围栏与侧栏选中态不跟随
点进智能合集「宽图合集」：顶栏标题正确变为「智能合集 · 宽图合集」，但①范围栏仍显示「所有资产 8 项」；②侧栏选中高亮仍停留在「所有资产」，「宽图合集」无选中态。

### B4【菜单逻辑】合集菜单互斥项恒同显
资产右键菜单中「移出合集：精选集」与「加入合集：精选集」**无论资产是否已在合成都同时显示且可点击**（已加入时仍可点「加入」、未加入时仍可点「移出」）。应按成员状态过滤或禁用其一。

### B5【工具栏溢出】右侧按钮组在 1567px 窗口下被裁切
「导入资源库」被裁成「导」；「导入 ZIP / 刷新磁盘变化 / 浏览器扩展 / 后台任务 / AI 设置」宽度为 0，完全不可见且不可点击，无溢出菜单（⋯）兜底。实证：这些功能在当前窗口宽度下从 UI 上消失。

### B6【空态错误】搜索无结果显示「这个文件夹还是空的」
在「所有资产」搜索 `zzznotfound`，空态文案为文件夹空态 + 导入按钮，误导用户以为文件夹空了。应为「无匹配结果」+ 清除搜索条件入口。

### B7【空态错误】回收站空态复用首次导入文案
清空回收站后显示「把第一批素材放进来 / 文件将复制到 Assets 目录」+ 导入按钮。回收站应有专属空态（如「回收站是空的」）。

## 四、UX 改进建议

- **U1** 父文件夹递归视图中，来自子文件夹的卡片无来源标识，分不清直属「素材」还是「插画」。建议卡片角标或分组显示来源文件夹。
- **U2** 搜索命中高亮会把分词文本（如 `wide red png`）额外显示在文件名下方一行，与文件名重复，视觉上像两行文件名。
- **U3** 多选时 Inspector 显示单个资产详情 + 批量提示条，而非「已选择 N 项」的汇总面板；批量场景下预览图与元数据属于哪个资产不明确。
- **U4** 无资源库时顶栏控件（搜索/智能合集输入/导入组）在视觉上与可用状态无差异，仅靠实际不可交互体现 disabled。
- **U5** 合集/智能合集视图中工具栏仍显示「导入文件/导入文件夹/粘贴图片」等，导入语义不明（导入后落在哪个文件夹？会不会自动加入当前合集？）。
- **U6** 「关闭资源库」按钮常驻右侧资源库信息面板底部，位置贴近常规浏览区，有误触风险（未测试是否有二次确认）。

## 五、工具限制与移交

- **拖拽验证移交**：CU 合成拖拽对 HTML5 DnD 无效，「拖拽资产到文件夹的悬停高亮」（BUG-DND-001 用户报告经常无法高亮）与「拖拽预览样式」（DND-003 缩小/低透明度/圆角）无法经本途径验证 → 移交 Playwright E2E 或人工 QA。
- 「前进」按钮全程 disabled（后退再导航后前进栈似被清空），未深入，供后续排查。
- CU 截图保存在会话缓存目录、无法落盘仓库；本报告证据为 AX 树快照与操作记录。静态截图证据可由 Playwright `ux-audit` spec 后续补拍。

## 六、根因假设（供开发参考，非结论）

B1/B2/B3 均为「数据操作或导航后部分 UI 未刷新」，指向同一方向：**Worker 数据变更事件或导航状态变更后，侧栏计数、资源库信息面板、范围栏、侧栏选中态中的部分订阅者未被失效/通知**。建议排查 useLibraryStats / 导航 store 的订阅覆盖面，把「资产集合变更」「合集成员变更」「位置变更」统一进一个 invalidation 总线。
