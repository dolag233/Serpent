# 2026-08-01：自动化脚本面板与后台任务入口

> 工单：`Serpent-uzzy`、`Serpent-hrc2`

## 变更

- 脚本面板保持上下布局，首次打开不再填充默认脚本。
- 移除示例脚本恢复按钮和长篇桥接说明；资源库状态与能力摘要改为短文案。
- 运行结果区域扩大并支持滚动，长结果和 `console` 输出不再被固定高度截断。
- 最近运行记录改为列表，显示本地化状态、来源、命令完成数和运行日志入口。
- 统一底部操作区、历史操作按钮和更多工具菜单中的活动任务指示。
- 后台任务入口从常驻画布工具栏移入“更多工具”，无资源库时置灰。

## 验证

- `npx vitest run tests/unit/toolbar-commands.test.ts`：15/15 通过。
- `npm run typecheck`：主 TypeScript 与扩展 TypeScript 通过。
- 当时的 `node scripts/run-e2e.mjs tests/e2e/automation-script-console.test.ts`：1 passed（6.3s）；覆盖首次空编辑器、结果区域滚动样式、脚本执行后状态、常驻工具栏无后台任务按钮，以及“更多工具 → 后台任务”入口。2026-08-03 按产品反馈撤回无资源库创建面板中的脚本入口后，该测试改为验证入口不存在；已有资源库内的脚本面板由脚本文件操作 E2E 继续覆盖。

## 人类验收边界

自动化验证不替代真实桌面视觉验收。需人工确认脚本面板在窄窗、长输出、运行历史较多和亮/暗主题下的可读性，以及“更多工具 → 后台任务”入口的可发现性和活动指示。
