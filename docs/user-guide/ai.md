# AI 分析

## 先了解边界

MVP 的 AI 分析是 BYOK（Bring Your Own Key）云端能力：Serpent 不提供模型账号、代理或额度，也不提供本地模型。你提供的 API Key 会由桌面主进程使用系统安全存储加密保存，渲染界面和普通日志不会回显 Key。启用前请阅读设置中的免责声明：发送给供应商的是用于分析的图像、视频联系表或 3D 四视图，可能产生供应商费用。

当前设置支持五种 API 协议：DashScope Multimodal、OpenAI Chat Completions、OpenAI Responses、Anthropic Messages 和 Gemini Native。不同协议可填写 Base URL、API Key 和模型名称；模型可以从接口读取，也可以手动填写。

## 配置 AI

1. 打开「设置」→「AI」。Windows 从左上角「主菜单」→「设置」进入，macOS 也可以使用系统菜单。
2. 选择 API 格式，填写 API Key 和模型；必要时填写自定义 Base URL。
3. 选择生成语言（中文、英文、日文或韩文），点击「测试连接」。
4. 在「AI 写入开关」选择是否写入描述、标签和 AI 评分，并决定是否允许强制使用已有标签。
5. 如果希望导入后自动分析，显式打开「新增资产自动进行 AI 分析」。该开关默认关闭；未配置 Key、模型或协议时不会自动入队。
6. 保存配置。高级设置可调整并发分析上限（1–32，默认 16）、送入模型的图像最长边（512–4096 px，默认 2048）、最大标签数、描述长度、输出风格、评分标准和自定义提示词。

## 什么资产可以分析

- 图像和 RAW：使用缩放后的图像输入。
- 视频：Serpent 生成带时间编号的联系表，只把联系表发送给模型，不上传原始视频。
- 3D 模型：先生成四视图联系表，再发送给模型。
- 音频、文本和其他未列入图像/视频/模型注册表的格式：当前不支持 AI 分析。

## 自动分析和手动分析

导入完成后，只有在配置了协议和 Key 且打开自动分析开关时才会后台入队；模型名称为空或供应商配置无效时，任务会在处理阶段报告原因。导入不会阻塞浏览；图像会优先直接处理源图，无法解码时才回退到 ready 缩略图；视频需要联系表，3D 需要四视图派生物。若提示派生物未就绪，请先刷新媒体预览后重新分析。若应用恰好在派生输入就绪通知期间重启，任务可能需要在后台任务面板中再次重试。

手动分析可以在资产右键菜单选择「AI 分析」，也可以对多选资产使用批量操作。若只想分析还没有结果的资产，使用「AI 分析未分析项」。已有 AI 结果再次手动分析会强制重新入队；成功后原结果被原子替换，不保留历史版本。

AI 只写入独立的描述、标签和评分层。用户手动填写的描述、标签和其他人工元数据优先显示，AI 不会覆盖它们；AI 标签和人工标签分开记录，但在资产上可以同时看到。清除 AI 内容可以作用于单项、当前选择、文件夹或整个资源库，批量清除需要确认，不会删除人工内容或标签实体。

## 队列、失败和重试

从「窗口」→「后台任务」打开任务面板，可以查看排队、运行、暂停、失败和已完成的 AI 任务。面板支持暂停/继续整个 AI 队列、取消、重试失败项，并可打开诊断日志。

网络、限流、超时和部分无效响应会按可靠性策略自动重试；认证、权限、额度或不支持格式等问题需要修正配置或源文件后再试。失败提示会带简短原因；部分失败以非阻断通知展示，全部失败可能显示更明确的失败提示，但不会删除已完成结果。视频联系表或缩略图失败时，先在任务面板重试媒体生成，再重试 AI。

## 隐私和成本

Serpent 不上传整个资源库，也不提供 AI 搜索。只有明确入队的可分析资产会按当前配置发送给所选第三方供应商；请根据供应商条款、数据敏感性和费用限制选择模型。API Key 不要写入脚本、插件或 MCP 参数。
