# 故障排查

## macOS 提示"无法验证开发者"

当前版本未签名公证，这是 Gatekeeper 的正常行为。右键点击应用 → 打开，仅首次需要。

```bash
xattr -cr /Applications/Serpent.app
```

## Windows SmartScreen 警告

未签名版本的正常提示。选择「更多信息 → 仍要运行」。

## 视频没有预览 / 缩略图

视频处理依赖 FFmpeg 组件。正常情况下组件随应用分发；如果出现 `FFMPEG_REQUIRED` 提示：

1. 确认安装的是完整安装包（非精简副本）
2. 完全退出应用后重新打开——恢复后 Serpent 会自动重试失败的预览任务

## 3D 模型（FBX）无法转换

FBX 转换依赖 ufbx 组件。报"转换组件不可用"时，重新安装应用即可恢复（组件随包分发）。OBJ/GLB/STL 不依赖该组件。

## 图片导入后显示破损图

通常是缩略图生成失败。重新打开资源库会自动补生成失败的缩略图。

## 资源库打不开

- 提示"只读"：资源库由更新版本的 Serpent 创建，或迁移多次失败。升级到最新版 Serpent 后重试
- 提示"损坏"：数据库或迁移记录异常。保留原目录，联系开发者并提供 `.serpent/` 目录内容

## 搜索不到已导入的资产

确认筛选条件（格式/尺寸/标签）没有误开，搜索字段使用正确语法（点击 `?` 查看）。

## 快捷键无反应

焦点不在画布上时部分快捷键不生效（如侧栏聚焦时）。点击画布空白处后重试。右键菜单弹出后 F2 重命名可能被焦点抢占，再次点击资产即可。

## 仍有问题

提供以下信息反馈（GitHub Issues）：

- 操作系统与版本
- Serpent 版本（「设置」中查看）
- 复现步骤
- `.serpent/` 目录中的日志（如存在）
