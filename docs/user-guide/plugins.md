# 插件使用

插件可以为 Serpent 增加新的工具、菜单或工作流程。插件不属于资源库中的普通资产，安装后可以随时启用或停用。

## 安装插件

1. 打开「设置」→「插件」，点击安装。
2. 选择插件来源：本地文件夹、本地 ZIP，或 GitHub 地址。
3. 如果从 GitHub 安装，直接粘贴插件项目地址即可。例如：

   `https://github.com/dolag233/Serpent-Plugin-ImageUpscaler`

4. 选择安装到「全局」或当前资源库。全局插件可用于所有资源库；资源库插件只在当前资源库中使用。

安装完成后，插件会出现在插件列表中。插件作者如果提供了使用说明，请按插件自己的说明完成配置。

![插件管理和安装入口](../assets/ui/extension.png)

## 启用和停用

- 在插件卡片上打开「启用」即可使用。
- 第一次启用资源库插件时，Serpent 会询问是否信任它；只有确认来源可靠时才选择信任。
- 暂时不用时关闭「启用」，需要时再打开。
- 修改插件设置后可以点击「重载」，不必重启 Serpent。

如果同一个插件同时安装了全局版和资源库版，插件列表会提示当前使用的版本，可以在那里切换或停用。

## 更新和卸载

GitHub 插件可以在插件设置中检查更新。自动更新默认关闭，开启前请确认插件来源。

卸载插件不会删除它可能保存的个人设置。如果以后重新安装同一个插件，希望保留原来的配置，可以直接重新安装；若插件提供了自己的清理入口，优先使用该入口。

## 浏览器扩展

浏览器扩展（Chrome / Edge / Firefox）的安装与使用见[浏览器扩展](browser-extension.md)。

## 遇到问题

如果插件没有出现在列表中、启用后没有反应，先检查插件是否安装在正确的范围，并重新打开插件设置。仍然无法使用时，请联系插件作者，并附上 Serpent 版本、操作系统和插件名称；不要在反馈中公开 API Key 或其他隐私信息。

开发者请阅读[扩展作者手册](../manual/README.md)。
