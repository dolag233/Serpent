### 动机

圆环 Hotbox 实测问题：命令分散、密度低、一级最多 8、返回上一级不符合直觉。改为**思维导图双栏**（方案 A：只同时显示「当前父级 + 其子项」）。

### 交互

| 手势 | 判定 | 结果 |
| --- | --- | --- |
| 拖拽媒体 | `dragstart`（开关开启） | 在拖起点附近弹出玻璃树状面板，页面压暗 |
| 悬停命令主体 | 矩形命中 `item` / `parent` | 高亮；松开 = **保存到该文件夹** |
| 悬停右侧 `›` | `drill`（仅 expandable） | AE 式水平推入下一级；左侧出现父级 pill |
| 悬停左侧 `‹` | `back` | 对称动画返回上一级 |
| 列表过长 | 指针靠列表上/下缘 | 自动滚动，一级命令数量不限 |
| 面板外松开 / Esc | `cancel` / Escape | 退出不保存 |

根级：仅右侧列表（快捷文件夹 +「根目录」）。非根级：左 = 当前父级（`‹` + 名），右 = 子命令列表。

## 需求来源与决策记录

用户原话（2026-07-25）：浏览器插件拖拽图片、视频等资产时显示 Serpent 保存菜单，对齐 Eagle 浏览器插件类似功能；菜单设计成类似 Houdini n 键菜单 / Maya Hotbox（游戏快速轮盘）：往一个方向移动表示选择该方向指令，可展开则再生成下一级轮盘，支持返回上一级，按 Esc 完全退出；多级菜单可任意选择保存位置。

2026-07-25 与产品负责人确认的三项决策：

| 决策点 | 结论 | 否决项 |
| --- | --- | --- |
| 可展开项的「展开 / 保存到它本身」手势 | **松开 = 保存进该文件夹；按住继续外甩穿越外环 = 展开下一级** | 松开展开+中心确认（多一步）；悬停停留展开（dragover 节流导致判定粗糙） |
| 轮盘应用范围 | **只做拖拽触发**；右键两套 UI（原生菜单 + 自绘浮层）不动 | 右键统一轮盘（本期不做） |
| 推进方式 | **先可交互 HTML 原型验证手感，再接入扩展** | 直接进扩展实现 |

原型第一轮用户反馈（2026-07-25，v2 已全部采纳）：

1. 视觉：不要纯黑楔形拼盘 → 灰色半透明玻璃圆盘（backdrop 模糊 + 细描边 + 分格线）；
2. 对齐：标签/图标必须与扇区严格对位（v1 存在容器锚点偏移 + 命中渲染半格错位两个缺陷，已修复并加断言）；
3. 松开判定：指针不在扇区环内时松开 = 直接退出，不保存；
4. 返回方位：子级的「返回」必须位于**进入方向的正对面**（从右上进入 → 返回在左下），符合空间直觉；中心圆统一为 ✕ 取消。

原型第二轮用户反馈（2026-07-25，v3 已全部采纳）：

5. **「返回」同样支持穿越外环触发**：穿越 =「执行该扇区的导航动作」，对文件夹是深入、对返回是退回，手势对称；几何上穿越返回后光标恰好落在父级中心圆（两侧半径相等、方向相对），不会反弹，另加穿越守卫兜底；
6. **取消「✓ 保存在此」扇区**：存进某文件夹直接在上一级松开于它的扇区即可，独立指令冗余；省出的槽位让子级内容从 6 个提升到 7 个。

原型第三轮用户反馈（2026-07-25，v4 已全部采纳）：

7. **删除装饰性 emoji 图标**（📁/🗂/🗄/⌂）：扇区整体就是文件夹按钮，图标无独立功能且视觉嘈杂；标签改为纯文字单行；
8. **同级重名消歧**：截图暴露出两个「角色」（`参考/角色` 与 `概念设计/角色`）无法区分——同级出现重名时自动展开为完整路径标签，且指针武装某文件夹时面包屑实时显示完整保存目标（`保存到：参考 / 角色`）。

原型第四轮用户反馈（2026-07-25，v5 定稿并接入实现）：

9. **图标保留但换形态**：v4 的纯文字太素，图标需要保留——改为单色线性 SVG 图标（文件夹/根目录房子/全部文件夹九宫格/返回 ‹/更多 ⋯），最近项叠加 accent 时钟角标；
10. **根级轮盘着重显示最近保存位置**：最近项占据 12 点起顺时针的黄金位置（第 1 名在正上方），并加 accent 浅蓝常驻底 + 时钟角标，与「返回」浅底视觉同级；
11. **冻结几何参数**：外径 120px、中心半径 45px（产品负责人在原型上调定）；随即接入扩展实测，不再继续纸面迭代。

接入后真实浏览器实测反馈（2026-07-25，v6 已全部采纳）：

12. **全屏压暗**：轮盘打开时页面叠加 `rgba(0,0,0,0.4)` 压暗层（150ms 淡入），凸显玻璃圆盘；压暗层 `pointer-events:none`，不干扰拖拽事件流；
13. **拖拽幽灵改缩略小图**：原生幽灵是全尺寸快照、按抓取点锚定，会遮住轮盘中心与扇区——`dragstart` 内同步把指针下媒体元素绘制进 **≤96px 画布缩略图**并 `setDragImage(canvas, 0, 0)`，光标固定在幽灵左上角；绘制/快照失败（跨源/DRM 视频、无内联尺寸 SVG 等）静默回退原生幽灵。品牌化幽灵小卡仍为后续打磨项；
14. **设置开关**：扩展选项页新增「拖拽网页图片/视频时显示保存轮盘」（默认开，`chrome.storage.sync`，content script 缓存并监听 `storage.onChanged` 实时生效；关闭时完全不介入原生拖拽）。

## 交互模型

拖拽是「按住左键」的手势，与游戏轮盘「按住-甩方向-松开」天然同构。整个选择过程是一次不松手的连续动作：

| 手势 | 判定 | 结果 |
| --- | --- | --- |
| 在图片/视频上按下并拖动 | content script `dragstart`（设置开关开启时） | 轮盘以拖动起点为中心展开（视口边缘自动夹取），页面压暗，拖拽幽灵锚点改为左上角 |
| 朝某方向甩 | `dragover` 坐标 → 相对中心角度/距离 | 高亮该方向扇区（中心圆以外即生效） |
| 在扇区环内松开 | `drop`，且 hub < d ≤ 扇区外径+8px | 执行扇区：保存 / 展开 / 翻页 / 返回 |
| 在可展开扇区上继续外甩穿越外环 | d > 展开半径（且穿越守卫已武装） | 执行该扇区的导航动作：文件夹/「全部文件夹」= 展开下一级，「‹ 返回」= 退回上一级，「更多 ▸」= 翻页；展开时**新轮盘以当前光标为中心**，可继续连甩 |
| 在「‹ 返回」扇区上松开 | 同环内松开 | 返回上一级（该扇区固定在**进入方向的正对面**） |
| 中心圆（✕）或环外任意位置松开 | d < hub 或 d > 扇区外径+8px | 退出，不保存 |
| Esc | 浏览器原生取消拖拽 → `dragend` | 完全退出，不保存 |

防误触规则：

- **释放范围判定**：只有落在扇区环内（hub < d ≤ ringOut + 8px 容差）的松开才执行动作；中心圆与环外任何位置的松开一律退出不保存，与原生拖拽「未命中目标即无效」语义一致。
- **角度常驻**：光标越过外环后扇区保持武装不丢失，只有角度变化才切换。
- **展开单向**：穿越展开后新轮盘中心即光标位置（距离为 0，位于中心圆），天然不会连锁展开。
- **穿越守卫**：每次层级切换（展开/返回/翻页）后，光标必须先回到展开半径以内一次，才允许下一次穿越。穿越返回的落点本就在父级中心圆附近（两侧等径、方向相对，几何证明见原型单测），守卫负责兜住快速甩动导致的越界落点，杜绝来回弹跳。

## 返回方位（v2 核心规则）

每次展开记录**进入方向** `entryAngle`（父级被穿越扇区的中线角）。子级轮盘整体旋转 `rotation = entryAngle + π − TOP`，使「‹ 返回」扇区（固定 index 0）的中线恰好等于 `entryAngle + π` —— 即指向父级轮盘中心的方向。用户沿原路反甩即可返回，多级连甩时每一级的返回都指向来路。

角坐标系约定（命中与渲染共用，杜绝 v1 的半格错位）：扇区 i 中线 = `TOP + i·(2π/n) + rotation`，扇区跨度为中线 ± 半格；`sectorAt(angle)` 是该映射的严格逆运算（单测覆盖：任意 n、任意 rotation 下 `sectorAt(midAngle(i)) === i`）。

## 状态机

```
idle ──dragstart(媒体)──▶ wheel(root)
wheel(root) ──穿越外环 on 全部文件夹▸/含子级的最近文件夹──▶ wheel(sub)
wheel(sub)  ──穿越外环 on 含子级文件夹──▶ wheel(sub')   （深度不限）
wheel(sub)  ──松开/穿越外环 on 「‹ 返回」──▶ wheel(上一级)
wheel(any)  ──松开 on 文件夹/根目录（环内）──▶ saving ──▶ toast ──▶ idle
wheel(any)  ──松开 on 中心✕/环外，或 Esc──▶ idle
wheel(any)  ──松开/穿越 on 「更多 ▸」──▶ 同层翻页
```

未连接 Serpent：不展开轮盘，光标旁显示提示气泡（约 1.8s 淡出），拖拽按浏览器原生行为继续。

## 轮盘内容与布局

每级最多 **8 个扇区**，等角均布；根级扇区 0 固定在 12 点方向，子级按「返回方位」规则整体旋转。

**根级（最近位置着重显示，v5）**

1–5. **最近使用文件夹 ×N**（≤5，复用既有 `recentFolderIds` 排序）：最近第 1 名固定在 **12 点位**，顺时针递次；accent 浅蓝常驻底 + 时钟角标，是轮盘的第一视觉优先级。含子级的可穿越展开。
6. `根目录`（保存目标：managed_folder_id = NULL，房子图标）
7. `全部文件夹`（纯导航项：松开或穿越都展开；不是保存目标，九宫格图标）

零最近记录的新库：根级仅 `根目录` + `全部文件夹` 两项。

**「全部文件夹」级（index 0 = `‹ 返回`）**：顶层文件夹 ≤7 个时全展示（返回+7=8）；超出则每页 6 个 + `更多 ▸`（返回+6+更多=8）。

**文件夹级（index 0 = `‹ 返回`）**：子文件夹 ≤7 个时全展示（返回+7=8）；超出则每页 6 个子级 + `更多 ▸`（返回+6+更多=8）。**无「保存在此」**：存进某文件夹在上一级松开于它的扇区即可（v3 决策）。

- 「返回」扇区可松开触发、也可穿越外环触发（v3），有常驻浅底区别于保存扇区。
- **同级重名消歧**（v4）：同一级出现同名保存项时（如两个「角色」），这些项的标签自动展开为完整路径（`参考 / 角色`）。
- **中心圆**：所有层级统一 `✕ 取消`。
- **面包屑**：圆盘正上方胶囊，默认显示层级路径（根级「保存到 Serpent」）；指针武装扇区时实时切换为动作预告——保存项显示完整目标路径（`保存到：参考 / 角色`），导航项显示 `返回上一级` / `下一页` / `展开：全部文件夹`。
- **可展开标记**：扇区外缘 `▸`；武装可展开扇区时外环方向出现半透明引导弧（含义：继续外甩执行导航动作）。
- **文案**：纯文字单行标签（无图标），最长约 112px，超出省略；toast 显示完整路径（`已保存到：参考 / 角色`）。

## 数据流与扩展接入点

复用既有链路，**无新增桌面端协议**：

1. `content-script.ts` 新增 `dragstart`（capture）监听：`resolveMediaTargetAtPoint` 复用既有媒体识别；命中媒体才进入轮盘流程，否则放行。命中时同步把幽灵替换为 ≤96px 画布缩略图（锚点左上角，v6），再异步展开轮盘。整个监听受选项页「拖拽网页图片/视频时显示保存轮盘」开关控制（默认开；关闭时不介入原生拖拽，幽灵也不改）。
2. 轮盘打开时通过既有 `serpent-list-folders` 消息取扁平文件夹列表，前端按 `relativePath` 建树（纯函数）；最近顺序复用 `recentFolderIds`（保存成功后 background 既有逻辑已会更新）。
3. `dragover`（capture，document）：坐标 → 角度/距离 → 武装扇区；光标在轮盘作用域内时 `preventDefault()` 允许 drop 并抑制页面自身 dragover 反应。
4. `drop`（capture）：环内命中保存目标 → `preventDefault()` + 既有 `serpent-save-request` 消息（`targetFolderId`）；轮盘关闭。环外/中心不拦截，按取消处理。
5. `dragend`（capture）：任何结束都关闭轮盘；Esc 由浏览器原生取消拖拽触发 `dragend`，无需额外键盘处理。
6. 保存反馈：系统通知行为不变（选项页可关）；轮盘保存成功后在页面内显示短暂确认 chip（对齐 Eagle 的即时反馈感）。
7. **所有站点生效**（不限 `overlay-hosts` 名单）；Shadow DOM 隔离页面样式。
8. 拖拽幽灵图：v6 起替换为 ≤96px 画布缩略图（锚点左上角）；品牌化幽灵小卡列入打磨项。

实现结构（2026-07-25 已接入）：几何/树/分页/消歧纯逻辑在 `extension/radial-menu-model.ts`（`sectorAt`、`midAngle`、`rotationForEntry`、`buildFolderTree`、`itemsForLevel`、`pageCountForLevel`、`disambiguateLabels`、`armedCrumb`、`isReleaseInRing`、`clampCenter`），DOM/SVG 渲染与拖拽事件在 `extension/radial-menu.ts`（Shadow DOM，`dragstart`/`dragover`/`drop`/`dragend` capture 监听，保存复用 `serpent-save-request`）；`background.ts` 的 `serpent-list-folders` 响应新增 `recentFolderIds` 供根级最近项着重显示（无桌面端协议变更）。单测 `tests/unit/radial-menu-model.test.ts`（21 例）。

## 异常态

| 场景 | 行为 |
| --- | --- |
| Serpent 未连接 / 无打开资源库 | 不展开轮盘；光标旁气泡提示「未连接 Serpent，请先启动应用并打开资源库」 |
| 文件夹列表拉取失败 | 根级仅保留「根目录」可保存（与既有浮层降级策略一致） |
| 保存被拒/下载失败 | 轮盘已关闭；沿用既有通知文案（`notificationForOutcome`） |
| 页面自身劫持 dragstart/dragover | capture 阶段先拿到事件；轮盘作用域内 `stopImmediatePropagation()` |
| 拖出窗口/拖进其他应用 | `dragend` 关闭，无副作用 |

## 边界 / 不做（本期）

- 右键保存两套 UI（原生菜单、Pinterest 等自绘浮层）保持不变。
- 不选资源库（保存目标 = 当前聚焦窗口的活动资源库，既有行为）；多库选择列为后续候选层级。
- 批量拖拽、保存进度展示、自定义拖拽幽灵小卡、轮盘皮肤/主题。
- 视频拖拽覆盖有限：原生 `dragstart` 主要由 `<img>`/链接触发，多数站点的 `<video>` 本身不可拖拽（站点自定义交互），本版以图片为主；视频拖拽的兜底方案列入后续评估。
- Firefox（首发仅 Chromium 系，沿用 0008 边界）。
